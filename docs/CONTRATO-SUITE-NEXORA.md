## 1. Objeto del Contrato

El presente contrato regula la concesión de uso de los programas de computación
desarrollados por el Licenciante bajo la marca comercial **NEXORA**, entregados en
formato ejecutable (EXE para Windows de escritorio) y aplicación móvil (APK para
Android), y que operan de forma **100% offline** en los equipos del Licenciatario.

La Suite NEXORA se compone de las siguientes aplicaciones:

| Aplicación | Plataforma | Descripción |
|---|---|---|
| **NEXORA Sistema MultiAlmacen v3** | Windows (EXE) | Gestión comercial: inventario multi-almacén, facturación POS, vales de entrada/salida, transferencias, ajustes (mermas/devoluciones/vencidos), Modelo D-01 ONAT, reportes y auditoría. |
| **NEXORA POS Móvil v2** | Android (APK) | Punto de venta móvil que importa inventario del almacén central (IPV), vende offline y devuelve el cierre de turno para reconciliación. |
| **NEXORA RRHH v1** | Windows (EXE) | Gestión integral de Recursos Humanos: expediente del personal, puestos de trabajo, asistencia, permisos/ausencias, nómina y vacaciones. |

Queda excluida de este contrato la aplicación **Generador de Licencias**
(MultiLicencias), que es una herramienta interna del Licenciante y no se entrega
ni se licencia al Licenciatario.

(mensual, trimestral, semestral o anual).

- Se concede una licencia por cada aplicación y por cada equipo en el que se instale.
